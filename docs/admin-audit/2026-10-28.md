# Admin panel audit, 28 Oct 2026

Scope: every `/admin` screen, with a focus on automation, marketing and promotions. Evidence is
the code on `main` (6f55f81), read-only queries on the production database, and the Vercel env
var **names** (values not read). The live admin needs Google sign-in, so screens were not clicked
on production; they were checked in code and against live data.

**Works** = does its job today. **Broken** = doesn't do what it says. **Weak** = works, but leaves
money or customers on the table. **Off** = built, but switched off by a missing setting.

## The uncomfortable part first

1. **The marketing engine has almost nobody it may legally message.** Of the ~2,400 people the
   admin knows, 2,386 come from the imported old-members sheet, which has no consent. Only
   **1** member, **9** leads and **4** email subscribers exist. Campaigns, renewal reminders,
   win-back offers and review requests all run off the member list, and the member list is empty.
   No code fix changes this. The member register (with end dates) has to be uploaded, and new
   people have to opt in.
2. **Every automated WhatsApp, not just promotions, fails while Meta billing is broken.** Diet
   plan receipts ("diet-received", "diet-plan-ready") also failed with 131042 on 24 Oct. Paying
   customers missed their WhatsApp; the email copies did go out.
