# Data Licenses

This file summarizes licenses for all integrated providers. Always check upstream for latest.

- **wger**: AGPL-3.0 — attribution required, share-alike if you modify wger code. Data use allowed with attribution.
- **Open Food Facts**: ODbL for database, DBCL for contents, images CC BY-SA. Attribution required.
- **USDA**: Public Domain (US Government) — no restrictions, attribution appreciated.
- **openFDA**: Public Domain — no restrictions.
- **RxNorm**: UMLS Metathesaurus License — RxNorm free but UMLS license required for full use. Check https://www.nlm.nih.gov/research/umls/
- **PubChem**: Public Domain — no restrictions, attribution to NCBI.
- **PubMed**: Metadata public domain, article licenses vary. Do not redistribute full articles without checking.
- **ClinicalTrials.gov**: Public Domain.
- **ICD-10**: WHO ©, CC BY-ND 3.0 IGO for browser. Local subset used under fair use + WHO terms. For commercial redistribution, get WHO license.
- **SNOMED CT**: Requires SNOMED International affiliate license (free for many countries via NLM, but commercial requires license). Self-host required.
- **Ayurveda**: Traditional knowledge (public domain old texts) + CC BY-SA for Wikipedia + open datasets (Amidha MIT). Use with disclaimer.
- **Homeopathy**: Boericke 1901, Allen etc. are public domain (pre-1928). Modern materia medica may be copyrighted — we use public domain only.
- **EKA / Indian Medicines**: Commercial, requires partnership. Marked LICENSE_REVIEW — do not use without agreement.
- **World Bank**: CC BY 4.0 — attribution required.
- **Open-Meteo**: CC BY 4.0 — attribution required.

If licensing unclear, marked LICENSE_REVIEW_REQUIRED and not auto-imported.
